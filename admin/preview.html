هذه أداة محلية داخل المتصفح لمراجعة شكل الرسالة. لا تحفظ النص على خادم، ولا ترسل إشعاراً، ولا تملك مفاتيح GitHub. النشر الحقيقي يتم حصراً من حساب المالك عبر GitHub Actions.

الانتقال إلى النشر بحساب المالك

اختر Run workflow ثم mode=preview للفحص أولاً. للنشر اختر publish واكتب PUBLISH، ولإيقاف رسالة سابقة اختر disable واكتب DISABLE. لا تستخدم هذا الرابط لنشر APK.
