# دليل رسائل إدارة Shbeeb Apps — بدون Push

**تاريخ التحقق:** 20 نوفمبر 2026. **الوضع:** الملفات البرمجية وCI محفوظة، لكن لا يوجد إثبات وصول رسالة فعلية إلى هاتف المالك. لا تنشر ملف APK عام في هذا المستودع.

## 1) تفعيل GitHub Pages (مرة واحدة)

افتح إعدادات مستودع `mustafashbeeb/Shbeeb-Downloader-Releases`، ثم:

`Settings → Pages → Build and deployment → Source: Deploy from a branch → main → / (root) → Save`.

بعد التفعيل تحقّق من فتح:
- `https://mustafashbeeb.github.io/Shbeeb-Downloader-Releases/`
- `https://mustafashbeeb.github.io/Shbeeb-Downloader-Releases/admin/preview.html`
- `https://mustafashbeeb.github.io/Shbeeb-Downloader-Releases/beta/`

هذه العناوين **مُخطط لها**؛ لا تُعتبر فعالة حتى ينجح اختبار HTTPS بالفعل. **لا تنشئ** `beta/android.json` بإصدار افتراضي، بل من APK Beta31 خاص موقّع ومراجع وفق المشروع الأساسي.

## 2) كتابة ومعاينة الرسالة

صفحة `admin/preview.html` للمعاينة فقط. فيها عنوان ونص وجمهور (الجميع / Beta / رسمي) وفئة ومدة، وتعرض شكل البطاقة العربية. **لا تجمع بيانات، ولا تكتب في GitHub، ولا تحفظ رموزاً سرية، ولا تنشر الرسائل**؛ هي صفحة عامة ويمكن لأي شخص فتحها، لكن لا تملك أي صلاحية نشر.

يمكن نسخ بيانات الرسالة منها، ثم الانتقال إلى [سير نشر رسائل صاحب التطبيق](https://github.com/mustafashbeeb/Shbeeb-Downloader-Releases/actions/workflows/owner-announcements.yml).

## 3) النشر بحساب المالك فقط

من صفحة Actions في GitHub اختر `Run workflow` على `main`، واملأ حقول العنوان والنص والجمهور والفئة والمدة.

- أولاً `mode=preview`، ولا تُكتب أي رسالة على الموقع. إذا تركت **العنوان والنص معاً فارغين**، يستخدم الفحص رسالة نموذجية آمنة بدلاً من الفشل؛ هذه المعاينة لا تُنشر ولا تصل إلى أي هاتف. إذا كتبت أحد الحقلين، يجب ملء الحقل الآخر أيضاً. شكل البطاقة يظهر في صفحة المعاينة السابقة.
- بعد مراجعة النص يدوياً اختر `mode=publish` واكتب `PUBLISH` حرفياً في حقل `confirm`. التشغيل المصرّح به فقط يمكنه إنشاء `announcements.json`.
- لإيقاف الرسالة في أي وقت: `mode=disable` واكتب `DISABLE`. لا يحتاج إيقاف رسالة إلى تحديث APK.
- لا تحتاج رسائل الإدارة إلى Push؛ التطبيق يقرأ الملف علناً عند الفتح/الفحص على فترات محدودة. **لا تصل الرسالة للتطبيق القديم Beta30**؛ يجب أولاً تثبيت إصدار يحوي قارئ رسائل الإدارة بعد نجاح اختبارات التحديث.

## 4) قواعد الأمان والخصوصية

- لا تضع GitHub Token أو كلمة مرور في صفحة معاينة، JavaScript، APK أو `announcements.json`.
- لا تُنشر روابط APK أو حزم خاصة أو مفاتيح توقيع هنا. مراجعة الحقوق [#64](https://github.com/mustafashbeeb/Shbeeb-Downloader/issues/64) مستمرة.
- العرض مقتصر على رسائل المالك؛ لا AdMob ولا ناشر خارجي ولا تتبع للمستخدمين.
- نافذة تحديث APK عبر `beta/android.json` **مختلفة** عن رسائل الإدارة عبر `announcements.json`. لا تدمج الخدمتين أو مفاتيحهما.
- Android Push للهاتف المقفل **مؤجل** إلى تحديثات لاحقة.
- إذا تعذّر اتصال الخدمة أو كانت الرسالة غير صالحة أو مُلغاة، لا يتوقف تحميل الفيديو/الصوت ولا يتغير السجل.

## 5) ما الذي لا يزال يحتاج اختباراً فعلياً؟

[ ] GitHub Pages يعمل عبر HTTPS، وContent-Type يطابق JSON عند إنشاء الرسالة.

[ ] نشر رسالة Beta واحدة بموافقة المالك، ثم اختبار ظهورها على هاتفه في إصدار يحتوي المستقبِل.

[ ] اختبار إخفاء الرسالة، منع تكرارها، الكتم، انقطاع الشبكة، سحب الرسالة، وانتهاء مدتها.

[ ] التأكد أن رسائل الإدارة لا تؤثر على سجل التنزيلات وشريط الأذكار أو القرآن.

هذا الدليل **لا يعني** أن إرسال الرسائل أو اختبار الهاتف قد اكتمل. للمراجعة التنفيذية: [Issue #66](https://github.com/mustafashbeeb/Shbeeb-Downloader/issues/66).
